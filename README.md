# ☕ Coffee Shop Sales Analysis Dashboard

## Overview
This project analyzes coffee shop sales data using Microsoft Excel to uncover key business insights. The dashboard helps track sales performance, customer purchasing patterns, product trends, and store-wise revenue through interactive visualizations and KPIs.

## Objectives
- Analyze sales trends by day, month, and hour.
- Identify peak sales periods.
- Compare performance across store locations.
- Determine best-selling products and categories.
- Calculate average order value and revenue metrics.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Power Query
- Data Visualization

## Key Insights
- Peak sales hours and busiest days.
- Monthly revenue trends.
- Top-performing store locations.
- Best-selling products by quantity and revenue.
- Sales distribution across product categories.

## Dataset
The dataset contains transactional sales records with:
- Transaction Date & Time
- Store Location
- Product Category & Type
- Unit Price
- Quantity Sold
- Sales Revenue

## Outcome
The dashboard transforms raw sales data into actionable insights, helping businesses make data-driven decisions to improve sales performance and operational efficiency.
